# ForTheKids

Sistema web para la gestión de campañas de donación de cabello.

## Estructura del repositorio

```text
ForTheKids/
|-- frontend/
|   `-- React/
|-- backend/
|   |-- src/
|   |   |-- controllers/
|   |   |-- routes/
|   |   |-- models/
|   |   |-- middleware/
|   |   `-- services/
|   `-- tests/
|-- database/
|   |-- migrations/
|   `-- seed/
|-- docs/
|-- .github/
|   `-- workflows/
|       `-- ci.yml
|-- .gitignore
|-- README.md
`-- .env.example
```

Los archivos `.gitkeep` mantienen en Git las carpetas que todavía no contienen código.
